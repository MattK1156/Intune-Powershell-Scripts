<h2>Tips for Win32 App Packaging : </h2>  
<li> Use `$PSScriptRoot` when specifying a separate file that was packaged with the Intunewin format. Intune runs in a temp directory so this variable tells it to look in the package extract directory </li>
<li> For install command always use `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "Install.ps1"`</li>
